# Hangman Game 🎮

A simple terminal-based Hangman Game built using Python.

This project allows users to choose a category and guess letters to find the hidden word before losing all 6 lives.
## Features ✨

- Multiple categories:
  - Movies
  - Animals
  - Foods
  - Names
- Colored terminal output using `colorama`
- ASCII Hangman drawing
- Lives system
- Displays guessed letters
- Beginner-friendly project
## Technologies Used 🛠️

- Python 3
- random module
- time module
- colorama package
## Installation 📦

### Install dependencies
install packages

## Game Rules 📜

1. Choose a category.
2. The computer selects a random word.
3. Guess one letter at a time.
4. You have 6 lives.
5. Each wrong guess removes one life.
6. Guess the word before all lives are lose
